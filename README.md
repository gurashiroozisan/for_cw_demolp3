# ねこひろば - デモサイト

ボランティアが育てた子猫の譲渡サイトのデモです。

## 技術スタック

- Next.js 15 (App Router)
- TypeScript
- CSS Modules

## ローカル開発

```bash
npm install
npm run dev
```

http://localhost:3000 で確認できます。

## Vercel へのデプロイ

1. GitHub にリポジトリをプッシュ
2. [Vercel](https://vercel.com) にログイン
3. 「New Project」→ リポジトリを選択
4. フレームワークは Next.js が自動検出されます
5. 「Deploy」をクリック

または Vercel CLI:

```bash
npm i -g vercel
vercel
```
